# TypeScale

Jerseys and Vinyles side by side: every type role in each app's own face and size, one row per role, so the two columns line up. The Typography section above lists the same styles by group; this card shows how the shared roles differ between the themes.

- Display face (page title, popup title, tabs, caption line 1): Jerseys sets Barlow Condensed italic, uppercase; Vinyles keeps Nunito.
- Page and popup titles are theme slots (`--heading-page-size`, `--heading-popup-size`); the caption is the same size in both apps, only the face and `--tracking-caption` change.
- Everything else is Nunito and the same in both columns.
