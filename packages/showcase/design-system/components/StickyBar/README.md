# StickyBar

The top of every list page, sticky at `layer-sticky` on `background`. Showcase `StickyBar.svelte`: the app gives the `title`, its `links` and the `chips`, `login`, `action`, `count`, `searchBox` and `controls` snippets.

- Row 1: the page title (`--heading-page-size`, display face), then on the right the Chips, LoginAction and ThemeToggle.
- Row 2: Tabs, the Owner's Add Button, the optional `count` Chip, and below 640px the search and filter icon toggles (an `icon-accent` dot marks a set search or filter).
- Row 3: SearchField, then filters, sort Select and SortDirection. Below 640px each half opens from its toggle.
- Jerseys: title "JERSEYS", pill Tabs, 44px icon buttons. Vinyles sets `packed`: "Vinyles." with the period in `icon-accent`, segmented Tabs, an `icon-sm` theme toggle, the toggles right after the Tabs, a title row that never wraps on a phone, Chips with icons.
