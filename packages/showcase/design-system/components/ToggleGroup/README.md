# ToggleGroup

Radio pills, `type="single"`: one option is always picked, and pressing it keeps it. Showcase `ToggleGroup.svelte` over `ui/toggle-group`.

The consumer gives a visible `label`, `options` (`{ value, label }[]`) and a bindable `value`. Pressed: `selected` and `selected-foreground` (the `--theme-selected` slot): the accent for Jerseys, sun for Vinyles. Used for Version, Size, Fit, Acquisition (Purchase / Gift).
