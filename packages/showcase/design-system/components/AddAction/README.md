# AddAction

The Owner's `success` "Add" Button next to the Tabs. Showcase `AddAction.svelte`.

It opens a centred form Popup titled `title` and renders `form(close)` in it; the form calls `close` when it is done. `wide` gives the form two columns from 640px (Jerseys); Vinyles keeps one column. Only the Owner sees it: no "owner only" text.
