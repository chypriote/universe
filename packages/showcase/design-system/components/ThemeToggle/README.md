# ThemeToggle

An icon Button that switches light and dark and saves the choice (`data-theme` on `<html>`, kept in localStorage). Showcase `ThemeToggle.svelte`.

`size`: `icon` (Jerseys) or `icon-sm` (Vinyles). Moon in light mode, sun in dark, with the hidden label "Switch to dark theme" or "Switch to light theme". Without a saved choice the system theme wins.
