# EmptyState

One line where the wall would be, with an optional way out. Showcase `EmptyState.svelte`.

The consumer gives `message` and an optional `action` snippet. Message in 14px / 700 `foreground`. Three cases in every app: an empty Collection ("No jerseys yet", "No records yet"), an empty Wishlist ("Nothing on the wishlist"), no match ("No match", with a neutral "Clear filters" Button).
