# Logos

Each app's mark, copied from its `static/` folder. They keep fixed colours in every theme; never recolour or redraw them. There is no wordmark: an app's name is set in its display face.

- `jerseys-mark.svg`: Jerseys favicon. A green-500 shirt with a sky-50 collar line and a sun-400 dot on a navy-800 square, 16/64 rounded corners.
- `jerseys-touch-icon.png`: the same mark as the Jerseys home-screen icon.
- `vinyles-mark.svg`: Vinyles favicon and app icon. A coral record with a sun label on a navy rounded square. In the UI the name is "Vinyles." with the period in `icon-accent`.
- `aviary-mark.svg`: Aviary favicon. A lime parakeet head with a navy beak and eye on a navy rounded square.
