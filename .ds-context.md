# Showcase

The shared design system of the collection apps (Jerseys, Vinyles, Aviary). Zhongguo has its own design family and is out of scope (`docs/adr/0001-design-families.md`).

- Design language: `packages/showcase/DESIGN.md`. Tokens: `packages/showcase/TOKENS.md`, code in `packages/showcase/src/showcase.css`. Components: `packages/showcase/COMPONENTS.md`.
- Each app's theme and component tokens: `apps/<app>/{DESIGN,TOKENS,COMPONENTS}.md` and `apps/<app>/src/app.css`.
- Design-system page: `packages/showcase/design-system/`, republished as `docs/design-system-page.md` says.
- No versions: apps use the workspace copy, so a breaking change updates every app in the same PR.

Review checklist for a Showcase change: `CODING_STANDARDS.md` at the repo root.
